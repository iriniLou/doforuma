# Работа с проектом

Перед правкой интерфейса, игровых текстов или ответом организатору прочитайте TEXT_STYLE.md и соблюдайте сохранённые редакторские предпочтения.

Используйте существующий checkout. Не меняйте реальные заголовки Google-таблицы и не помещайте данные участников в публичные файлы. Изменение integration/Code.gs требует новой версии существующего развёртывания Google Apps Script; push в GitHub сам этот скрипт не обновляет.
