# Подключение листа «Расселение»

Тест можно просматривать локально без подключения таблицы. Пока URL сервера пустой в `config.js`, раздел размещения честно показывает «Список размещения готовится».

В этой версии используются **только ФИО**. Почты не запрашиваются, не показываются и не сохраняются. Прогресс теста хранится локально, результаты поиска размещения — только в памяти страницы.

## Одна настройка владельцем таблицы

1. Откройте предоставленную Google-таблицу → Расширения → Apps Script.
2. Вставьте содержимое `Code.gs`. Проверьте название листа в `HOUSING.sheetName`. Если такого листа нет, скрипт выберет единственный лист с подходящими заголовками. Если подходящих несколько, задайте имя явно.
3. Разверните новый **Web app**: выполнять от имени владельца, доступ — пользователям, у которых есть ссылка (пункт «Все», если доступен в вашей организации). Подтвердите чтение таблицы только для вашего скрипта. Публиковать саму таблицу в интернет не требуется.
4. Скопируйте URL развертывания, заканчивающийся `/exec`, в `housingEndpoint` файла `config.js`. Не используйте URL редактора или `/dev`.
5. Откройте сайт, найдите известную фамилию, выберите ФИО и сравните соседей с таблицей. Проверьте одинаковые фамилии, человека без соседей и изменение строки. Google Apps Script возвращает JSON с редиректом; перед массовой рассылкой проверьте запрос именно с адреса GitHub Pages.

Владелец развернул Apps Script и предоставил URL `/exec`; он уже сохранён в `housingEndpoint` и `analyticsEndpoint`. Заголовки таблицы предоставлены организатором и поддерживаются без переименования. Настоящее подключение из этой среды не проверено: прокси отклоняет запрос до обращения к Google (CONNECT 403). Это не проверка разрешений Google-таблицы.

## Формат текущей таблицы организатора

Поддерживаются заголовки без переименования: `Фамилия 1`, `Имя 1`, `Отчество 1`, `Регион 1`, `Фамилия 2`, `Имя 2`, `Отчество 2`, `Регион 2`. Одна строка — два соседа. Поиск работает по обеим фамилиям; номер комнаты не требуется. Пустая вторая половина строки означает, что сосед пока не указан. Изменения и добавления строк считываются на следующем запросе. При совпадении полного ФИО в вариантах показывается регион.

После обновления `Code.gs` нужно сохранить код и обновить **существующее** развертывание: Начать развертывание → Управление развертываниями → выбрать текущее → карандаш → Версия: Новая версия → Развернуть. Тогда URL `/exec` останется прежним, изменение сайта для замены адреса не нужно.

## Другие поддерживаемые столбцы

* Полное `ФИО` / `ФИО участника`, либо отдельные `Фамилия`, `Имя`, `Отчество`.
* `Комната` / `Номер` / `Номер комнаты` / `ID комнаты` / `Группа расселения` / `room_id` для группировки соседей. Номер должен быть заполнен в **каждой строке участника**, без объединённых ячеек. При наличии `Корпус`, `Гостиница` или `Отель` они включаются в ключ комнаты.
* Альтернатива комнате — `ФИО соседа` / `Соседка` / `Соседи` / `С кем живёт`. Несколько ФИО разделяются `;` или переносом строки. В этом варианте это готовые имена соседей из строки человека.
* Для нестандартных названий заполните `HOUSING.columns` точными названиями столбцов. Их порядок не важен. Посторонние столбцы игнорируются.
* Необязательные `ID` / `ID участника` поддерживаются. Дополнительный признак для различения полных тёзок можно задать через `columns.detail`, например `Регион`. По умолчанию ничего, кроме ФИО, не выдаётся.

Каждый запрос заново читает текущий лист: исправления и новые строки не требуют изменения сайта или повторного развёртывания скрипта. Изменение кода скрипта требует обновить версию развертывания. Если строка поменялась между поиском и выбором, повторите поиск.

## Контракт API

`GET /exec?surname=Иванова` → `{status:"matches",matches:[{id:"...",name:"Иванова Анна ..."}]}`.

`GET /exec?surname=Иванова&id=...` → `{status:"room",self:{name:"..."},roommates:[{name:"..."}],updatedAt:"..."}`.

Ошибка → `{error:"unavailable"}`. Клиент не показывает внутренние сведения таблицы.

Поиск по фамилии позволяет участнику запросить чужую фамилию. Это соответствует текущему сценарию поиска, но не является проверкой личности. Для ограничения доступа потребуется отдельная авторизация или персональная ссылка. В публичных файлах сайта полный список отсутствует.

## Опрос до теста

Источник расселения — таблица `1QFGb1Yl0Uf6su9vzRjUUvvm8SjhClIf0AMxZn3De3Hw`, лист «Расселение». Ответы опроса записываются отдельно: `STATISTICS_SPREADSHEET_ID` указывает исходную таблицу `1ibR7COnJ6_TAQ7hgpH35j5f2dwG3OaFHUBfTJ6LY5a0`. Для скрипта нужен доступ на чтение к первой и на запись ко второй. Расселение при отправке анкеты не изменяется.

Кнопка «Отправить ответы» отправляет **все три ответа анкеты**: выбранную нехватку, способ подготовки и вопрос экспертам. Есть шесть готовых способов подготовки и свой вариант; если вопроса пока нет, можно поставить прочерк. Участник видит уведомление об анонимном учёте, без отдельной галочки по уточнению организатора.

`POST /exec` с JSON `{action:"survey",token:"<random-id>",need:"...",preparation:0,question:"..."}` (Content-Type `text/plain`). Сервер создаёт отдельный лист **«Ответы перед форумом»**. Столбцы: `Код ответа`, `Чего не хватает`, `Подготовка к занятию`, `Вопрос экспертам`. Старые листы и заголовки не меняются. Код ответа — случайный технический ключ, без привязки к поиску ФИО. Повтор с тем же ключом обновляет одну строку. Начало вопроса, похожее на формулу, сохраняется как текст.

Клиент ждёт `{ok:true}` после записи и `SpreadsheetApp.flush()`. При ошибке ответы остаются в браузере, можно повторить отправку. После подтверждения можно закрыть страницу: проходить тест для записи не требуется. При пустом `analyticsEndpoint` после заполнения опроса открывается явно обозначенный локальный режим просмотра. При подключённом API этот режим не заменяет подтверждение записи. Отдельная кнопка «Пропустить опрос» открывает тест и размещение без отправки и без отметки об успешной записи. Черновик остаётся на устройстве; вернуться к анкете можно с главной.

Первый ответ «Чего Вам сейчас не хватает?» также учитывается при расчёте персонажа в браузере. Ответы на пять вопросов короткого теста и его результат на сервер не отправляются. Повторное прохождение сохраняет ранее отправленную анкету.

Предоставленный владельцем URL `/exec` уже включён в `analyticsEndpoint` и `housingEndpoint`. При замене длинной игры коротким тестом серверный код не менялся; обновлять развёртывание Apps Script для этой замены не требуется. Фактическую запись в Google из облачной среды не проверяли: запрос блокирует прокси до обращения к Google.

## Прежние счётчики

Обработчик `action:"need"` оставлен для совместимости с ранней версией сайта. Он ведёт агрегаты в листе «Статистика игры» и подавляет повтор с тем же ключом в течение шести часов. Текущий сайт его не вызывает; новые анкеты нужно смотреть в листе «Ответы перед форумом».

## Свой вариант подготовки

К шести готовым ответам добавлен седьмой — «Свой вариант» (`preparation:6`). При его выборе обязательное поле `preparationOther` принимает до 1500 символов. Сервер записывает «Свой вариант: …» в существующий столбец «Подготовка к занятию». Заголовки и число столбцов не изменяются. Прочерк в вопросе экспертам допустим и сохраняется как текст.

Чтобы собственный ответ сохранялся, после замены `Code.gs` выпустите новую версию существующего развертывания. Его URL остаётся прежним. Первые шесть вариантов сохраняют прежний формат запроса.

## Ошибка unavailable и проверка владельцем

Общий `unavailable` старой версии не устанавливает причину: это может быть доступ к книге, защита листа, блокировка или сбой Google. 06.11.2026 настоящий `/exec` ответил на запрос без данных, а четыре заголовка листа ответов совпали с ожидаемыми. Эти чтения не проверяют право записи.

В обновлённом `Code.gs` добавлены коды `survey_busy`, `survey_workbook`, `survey_sheet`, `survey_sheet_create`, `survey_read`, `survey_write`, `survey_flush`. Полное исключение Google доступно только владельцу в журнале проекта; тело анкеты не логируется. Для применения:

1. В проекте Apps Script «Сайт форума» замените `Код.gs` содержимым актуального `Code.gs` и сохраните.
2. В списке функций рядом с «Выполнить» выберите **prepareSurvey** и нажмите «Выполнить». При необходимости подтвердите доступ своего скрипта. Функция не добавляет тестовые ответы и не меняет существующие заголовки.
3. Если функция завершится с ошибкой, её сообщение покажет следующую причину для исправления: доступ аккаунта к таблице, неверная книга, структура или защита диапазона. Если проверка пройдёт, опубликуйте **новую версию существующего** развёртывания: «Начать развёртывание» → «Управление развёртываниями» → карандаш → «Новая версия» → «Развернуть».
4. Веб-приложение должно выполняться от имени владельца с правом редактировать таблицу ответов; доступ — «Все». URL `/exec` сохраняется.

Пропуск опроса работает независимо от этой проверки. Пустую анкету не подменяем подтверждённой записью, черновик можно отправить позже.
