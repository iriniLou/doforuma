# Важное с собой

Игра перед II Всероссийским форумом молодых педагогов «Вместе о важном», 12–15 ноября 2026 года.

## Первая часть

Три предмета в чемодане, три главы, шесть сюжетных эпизодов, уточняющие вопросы, решения с последствиями и открытка в PNG. Предметы открывают дополнительные ходы, лупа даёт дополнительный вопрос. Предыдущие решения меняют продолжение и итог. Прогресс и необязательные заметки сохраняются в браузере; передачи ответов организаторам нет. Приблизительное время прохождения — 18–23 минуты; фактическое время пользовательского тестирования ещё не замерялось.

Оформление использует палитру приложенного брендбука «Разговоры о важном»: #FF553E, #63BAFF, #FF94CC, #93E479, #FFCC5B. Иллюстрация чемодана нарисована в SVG. Внешние шрифты, аналитика, рекламные скрипты и сетевые зависимости отсутствуют. Основной шрифт — системный Arial/sans-serif; фирменный PT Root UI не приложен к проекту.

## Открыть

Сайт статический, сборка для размещения не требуется:

```sh
cd /workspace/doforuma
python -m http.server 8000 --bind 127.0.0.1
```

Для пересылки одним файлом: `python build.py`, затем открыть `dist/Важное-с-собой.html` в браузере. Игра работает офлайн, раздел размещения требует сети и подключения API. Копия в одном файле использует отдельный локальный прогресс в зависимости от браузера.

## Размещение

Два входа доступны с главной. Поиск можно открыть на любом этапе игры. После уточнения требований используются только ФИО, без почт. Реальных данных в репозитории нет.

Подключение Google-таблицы: [integration/README.md](integration/README.md). Сервер читает живой лист при каждом запросе, находит точную фамилию, возвращает варианты полных имён и соседей выбранного человека. При отсутствии подключения показывается сообщение о подготовке списка. Структура настоящей таблицы и развёртывание сервера пока не проверены — нужен доступ к Google-таблице и аккаунт владельца для Apps Script.

## GitHub Pages

В репозитории: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. После успешной публикации ожидаемый адрес: `https://irinilou.github.io/doforuma/`. Адрес считается опубликованным только после проверки ответа сайта.

## Правки

* `content.js` — предметы, ситуации, вопросы, варианты и последствия.
* `app.js` — переходы, сохранение, открытка и поиск.
* `visuals.js` — рисованные SVG вещей и шесть игровых ролей.
* `style.css` — адаптивное оформление и движение с учётом prefers-reduced-motion.
* `config.js` — URL сервера поиска и необязательная ссылка на контакт в MAX.

Тексты участников и данные заявок в код не копируются. Для уникальных тёзок сервер может показывать дополнительный согласованный признак (например, регион) после настройки `columns.detail`.

## Проверки

```sh
node --check app.js
node --check content.js
node tests/housing.test.cjs
# При работающем локальном сервере, установленных Playwright и Chromium:
python tests/e2e.py
```

Проверяются полное прохождение на компьютере и телефоне, бонусные ходы, ограничения вопросов, восстановление прогресса, экспорт PNG, замена предмета, выбор однофамильцев, обновление ответа API, ошибки сети и отсутствие данных размещения в localStorage. API в браузерном тесте подменён тестовыми ответами. Серверный тест использует вымышленные данные и имитацию Google Sheets.

## Обновление: карточки и статистика

В финале — одна из шести карточек по последовательности решений: «Архитектор общего дела», «Режиссёр первого шага», «Мастер плана Б», «Ловец тихих голосов», «Навигатор смысла», «Хранитель заряда». Роль определяется игровыми действиями, не случайно и не по выбранному затруднению. Это игровой результат, не профессиональная диагностика. Все роли достижимы с доступными наборами предметов.

Открытка на экране и PNG используют одну SVG-композицию. Карточка роли скачивается отдельно. Рисунки вещей встроены в SVG и не зависят от символов шрифта. Пояснения к предметам доступны по наведению и фокусу.

Анонимные счётчики запросов подготовлены в `integration/Code.gs`. До настройки `analyticsEndpoint` данные не отправляются. После подключения добровольная отметка разрешает отправить одну категорию; тексты заметок, открытки, ФИО и поиск размещения не отправляются. Инструкции — в integration/README.md.
