# Какой Вы педагог?

Короткий шуточный тест перед II Всероссийским форумом молодых педагогов «Вместе о важном», 12–15 ноября 2026 года.

Сначала участник отвечает на три вопроса организаторов. После подтверждения записи можно выбрать тест или поиск соседей. Тест проходить необязательно для размещения.

## Тест

Пять вопросов о привычных рабочих ситуациях, примерно 2–3 минуты. В конце — один из шести персонажей: педагог-искра (лиса), навигатор (сова), капибара, изобретатель (енот), свой человек (пингвин) или подзарядка (кот). Это развлекательный результат, не профессиональная диагностика.

Результат зависит от пяти ответов и ответа «Чего Вам сейчас не хватает?» в первом опросе. Баллы нормируются по возможному максимуму каждого персонажа; при равенстве учитываются первоначальная потребность и последние ответы. Случайного выбора нет. Все шесть результатов достижимы. Перебор 5120 комбинаций даёт каждому персонажу около 14–20% результатов; это проверка алгоритма, не статистика участников.

Карточка на экране и скачиваемый PNG используют одну SVG-композицию с авторским рисунком, описанием и суперсилой. Изображения и шрифты загружаются без внешних сервисов. Палитра опирается на предоставленный брендбук «Разговоры о важном».

## Опрос и размещение

Опрос отправляется до доступа к тесту и размещению; завершение теста для записи не требуется. В вопросе подготовки есть «Свой вариант», в вопросе экспертам можно поставить прочерк. Ответы записываются в отдельный лист «Ответы перед форумом». Повтор при сетевой ошибке использует тот же технический ключ, без новой строки для той же отправки.

Google-скрипт и его контракт при замене игры не менялись. URL `/exec` уже указан в `config.js`. Новая версия развёртывания Apps Script для этой замены не нужна. Описание подключения и точные заголовки — в [integration/README.md](integration/README.md).

Поиск расселения читает актуальные строки при каждом запросе. Используются только ФИО; почт на сайте нет. При нескольких совпадениях участник выбирает полное ФИО. Заголовки исходной таблицы остаются прежними. Результаты поиска не сохраняются в localStorage. Реальных записей участников в репозитории нет.

Состояние теста хранится в браузере под ключом `forum-short-quiz-v1`. При первом открытии новой версии из старого сохранения переносятся только поля опроса и подтверждение его записи. Старый игровой прогресс остаётся в прежнем ключе `vazhnoe-game-v1`. «Пройти ещё раз» сбрасывает только пять ответов теста, сохраняя анкету.

## Запуск и сборка

Приложение статическое, зависимостей npm нет:

```sh
cd /workspace/doforuma
python -m http.server 8000 --bind 127.0.0.1
```

`python build.py` собирает `dist/Какой-Вы-педагог.html` для пересылки одним файлом. Опрос и размещение требуют сети; при пустом `analyticsEndpoint` явно включается локальный режим просмотра без отправки ответов.

GitHub Pages: ветка `main`, папка `/ (root)`. Адрес: https://irinilou.github.io/doforuma/. Доступ к опубликованному сайту и Google из облачной среды ограничен прокси; браузерные проверки используют перехват запросов и вымышленные ответы. Они не подтверждают запись в настоящую таблицу.

## Файлы

- `quiz-data.js` — вопросы, персонажи и расчёт результата.
- `quiz-art.js` — авторские SVG персонажей.
- `quiz-app.js` — экраны, опрос, поиск, сохранение и PNG.
- `quiz.css` — оформление для компьютеров и телефонов.
- `config.js` — URL Google Apps Script и необязательный контакт MAX.
- `TEXT_STYLE.md` — редакторские предпочтения организатора.

## Проверки

```sh
python build.py
node --check quiz-app.js
node --check quiz-data.js
node --check quiz-art.js
node tests/quiz.test.cjs
node tests/housing.test.cjs
node tests/analytics.test.cjs
node tests/survey.test.cjs
# При работающем локальном сервере, Playwright и /usr/bin/chromium:
python tests/quiz-browser.py
python tests/quiz-cards.py
```

Проверяются полный путь участника, отправка опроса до входа, выбор однофамильцев, восстановление теста, разные результаты при повторе, влияние первого ответа, PNG всех шести персонажей, экраны телефона, старое сохранение и недоступность старых игровых файлов. Google-запросы в тестах перехватываются: тестовые ответы не попадают в настоящую таблицу.

## Прежняя игра

Длинная версия «Важное с собой» удалена из публикуемых файлов. До замены сохранены исходники, история Git, собранная страница и отдельная копия для локального просмотра без отправки анкет. Архив передан организатору отдельно и не находится в папке сайта. В публичной истории GitHub старый код остаётся доступным.

Для возврата используйте исходники из архива в отдельной папке. Не копируйте их поверх действующего сайта без решения организатора. Старые тесты длинной игры включены в архив.
