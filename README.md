# Какой Вы педагог?

Короткий шуточный тест перед II Всероссийским форумом молодых педагогов «Вместе о важном», 12–15 ноября 2026 года.

На первом экране — три вопроса организаторов. Их можно заполнить или пропустить и сразу открыть тест либо поиск соседей. К анкете можно вернуться с главной. Тест проходить необязательно для размещения.

## Тест

Пять вопросов о привычных рабочих ситуациях, примерно 2–3 минуты. В конце — один из шести персонажей: педагог-искра (лиса), навигатор (сова), капибара, изобретатель (енот), свой человек (пингвин) или подзарядка (кот). Это развлекательный результат, не профессиональная диагностика.

Результат зависит от пяти ответов и, если он выбран, ответа «Чего Вам сейчас не хватает?» в первом опросе. При пропуске пустой анкеты первоначальная потребность не подставляется и не влияет на результат. Баллы нормируются по возможному максимуму каждого персонажа; при равенстве учитываются первоначальная потребность и последние ответы. Случайного выбора нет. Все шесть результатов достижимы. Перебор 5120 комбинаций даёт каждому персонажу около 14–20% результатов; это проверка алгоритма, не статистика участников.

Карточка на экране и скачиваемый PNG используют одну SVG-композицию с заново сгенерированными иллюстрациями в технике гуаши и цветного карандаша, описанием и суперсилой. Шесть прозрачных PNG хранятся в `assets/mascots/`; для просмотра загружается нужный персонаж, для экспорта рисунок встраивается в SVG. В однофайловую сборку встроены все шесть изображений. На карточке нет выбранной нехватки, пояснения к расчёту, пометки «Шуточный тест» или адреса сайта. Изображения и шрифты загружаются без внешних сервисов. Палитра опирается на предоставленный брендбук «Разговоры о важном».

## Опрос и размещение

Ответы отправляются только по кнопке «Отправить ответы»; завершение теста для записи не требуется. «Пропустить опрос» не валидирует поля, не отправляет запрос и не выдаёт пропуск за подтверждённую запись. Черновик сохраняется на устройстве; после ошибки можно пропустить и позднее повторить отправку с тем же ключом. В вопросе подготовки есть «Свой вариант», в вопросе экспертам можно поставить прочерк. Ответы записываются в отдельный лист «Ответы перед форумом». Повтор при сетевой ошибке использует тот же технический ключ, без новой строки для той же отправки.

URL `/exec` уже указан в `config.js`. Для работы пропуска опроса обновлять Apps Script не требуется. По ссылке `?skip-survey=1` тест и размещение открываются напрямую, в том числе без доступа к localStorage. Описание подключения и точные заголовки — в [integration/README.md](integration/README.md).

Поиск расселения читает актуальные строки при каждом запросе. Используются только ФИО; почт на сайте нет. При нескольких совпадениях участник выбирает полное ФИО. Заголовки исходной таблицы остаются прежними. Результаты поиска не сохраняются в localStorage. Реальных записей участников в репозитории нет.

Состояние теста хранится в браузере под ключом `forum-short-quiz-v1`. При первом открытии новой версии из старого сохранения переносятся только поля опроса и подтверждение его записи. Старый игровой прогресс остаётся в прежнем ключе `vazhnoe-game-v1`. «Пройти ещё раз» сбрасывает только пять ответов теста, сохраняя анкету.

## Запуск и сборка

Приложение статическое, зависимостей npm нет:

```sh
cd /workspace/doforuma
python -m http.server 8000 --bind 127.0.0.1
```

`python build.py` собирает `dist/Какой-Вы-педагог.html` для пересылки одним файлом. Опрос и размещение требуют сети; при пустом `analyticsEndpoint` явно включается локальный режим просмотра без отправки ответов.

GitHub Pages: ветка `main`, папка `/ (root)`. Адрес: https://irinilou.github.io/doforuma/. Доступ к опубликованному сайту и Google из облачной среды ограничен прокси; браузерные проверки используют перехват запросов и вымышленные ответы. Они не подтверждают запись в настоящую таблицу.

## Файлы

- `quiz-data.js` — вопросы, персонажи и расчёт результата.
- `quiz-art.js` — подключение иллюстраций и их встраивание для сохранения карточек.
- `assets/mascots/` — шесть заново сгенерированных PNG с прозрачным фоном.
- `quiz-app.js` — экраны, опрос, поиск, сохранение и PNG.
- `quiz.css` — оформление для компьютеров и телефонов.
- `config.js` — URL Google Apps Script и необязательный контакт MAX.
- `TEXT_STYLE.md` — редакторские предпочтения организатора.

## Проверки

```sh
python build.py
node --check quiz-app.js
node --check quiz-data.js
node --check quiz-art.js
node tests/quiz.test.cjs
node tests/housing.test.cjs
node tests/analytics.test.cjs
node tests/survey.test.cjs
# При работающем локальном сервере, Playwright и /usr/bin/chromium:
python tests/quiz-browser.py
python tests/survey-skip.py
python tests/quiz-cards.py
```

Проверяются полный путь участника, отправка опроса до входа, выбор однофамильцев, восстановление теста, разные результаты при повторе, влияние первого ответа, PNG всех шести персонажей, экраны телефона, старое сохранение и недоступность старых игровых файлов. Google-запросы в тестах перехватываются: тестовые ответы не попадают в настоящую таблицу.

## Прежняя игра

Длинная версия «Важное с собой» удалена из публикуемых файлов. До замены сохранены исходники, история Git, собранная страница и отдельная копия для локального просмотра без отправки анкет. Архив передан организатору отдельно и не находится в папке сайта. В публичной истории GitHub старый код остаётся доступным.

Для возврата используйте исходники из архива в отдельной папке. Не копируйте их поверх действующего сайта без решения организатора. Старые тесты длинной игры включены в архив.

## Диагностика записи анкет (06.11.2026)

Существующее развёртывание возвращает общий `unavailable`, который сам по себе не указывает причину. Запрос без фамилии подтвердил ответ настоящего `/exec`; отдельно прочитаны только четыре заголовка листа «Ответы перед форумом», они совпадают с контрактом. Запись в настоящую таблицу автоматически не выполнялась.

`integration/Code.gs` теперь различает ошибки блокировки, открытия книги, создания листа, чтения, записи и подтверждения. Подробность Google логируется только внутри проекта; клиент получает код этапа, без текста анкеты. Полностью пустой лист инициализируется, существующие заголовки не меняются. Ручная `prepareSurvey()` проверяет доступ и защиту A2:D2, готовит пустой лист без тестовых анкет. Чтобы применить эту часть, владельцу нужно заменить код в Apps Script, выполнить `prepareSurvey` и опубликовать новую версию существующего развёртывания. Один push в GitHub серверный скрипт не обновляет.
